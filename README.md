## 프로젝트 개요

귓속말 기능과 멀티스레드 처리를 지원하는 서버-클라이언트 구조의 채팅 어플리케이션입니다. Java Swing GUI와 소켓 프로그래밍을 활용하여 구현되었습니다.

## Requirements
베이스코드 주석 추가 및 개인 코드 구현

다중 클라이언트 동시 처리 가능한 서버

 채팅방 정보 관리 및 모든 유저에게 상태 전파

 GUI를 통한 귓속말 기능 구현

 serverinfo.dat 파일을 통한 서버 정보 관리

 서버 측 유저 정보 관리

 Login, Register 기능 구현

 중복 user_id 동시 접속 차단

 Hash와 Salt를 이용한 비밀번호 암호화 저장

 로그인 성공 시 서버에서 유저 접속 상태 관리
